# 长程足迹（append-only）

> 每轮派发的执行 agent 完成后追加**一条**（由 moa_footprint_append 写入，格式如下）。
> 无进展的轮次也必须记录——把没做成的改名成成功视为作弊（loopx：no-progress ≠ success）。
> 证据用 ref（`commit:<sha>` / `smoke:<用例名>` / `pr:<编号>` / `run:<运行id>`），todo 完成/自述不算证据。

## 条目格式（每轮一条，锚定「做了什么/验证/证据/负结果/下一步」）

```
## <任务 ID> <标题>（<ISO 时间>）
- 做了什么：<关键动作，含文件路径>
- 验证：<命令 + 结果>（或「未验证」）
- 证据：<ref>（无则写：无 ref（todo 完成/自述不算证据））
- 结果：<done | blocked | partial>（partial 需在 state note 保留进度）
- 负结果：<失败尝试/未达成的验收>（无则写「无」；无进展轮次必须写明原因）
- 下一步：<留给下一轮的问题或建议>（无则写「—」）
```
